# Accounting (记账)

一款注重隐私和本地存储的个人安卓记账应用。

本应用采用统一的资产管理模型，将每一个余额持有方（现金、银行卡、微信支付、支付宝、苹果账户余额、公交卡等）都视为一个“账户”。这使得转账追踪和还原现实消费场景变得非常精确。

## 核心功能

- **资产账户管理**：追踪多种账户类型的余额（现金、银行、第三方支付等）。
- **灵活的交易类型**：
    - **支出/收入**：基础的现金流追踪。
    - **转账**：记录账户间的资金流动（不计入收支统计）。
    - **余额校正**：轻松对账，使数字余额与现实金额保持一致。
- **预算系统**：
    - **月度预算**：设置每月的总支出上限。
    - **分类预算**：为不同的消费类别（如餐饮、交通）设置具体限额。
- **周期性交易**：设置每月自动生成的定期规则，简化固定账单和收入的记录。
- **分类与标签系统**：
    - 完全可自定义的分类，支持图标和颜色选择。
    - 标签系统支持跨分类分析。
- **统计与洞察**：
    - 周、月、年汇总。
    - 分类占比图表及月度支出趋势。
- **数据安全与便携性**：
    - **本地优先**：所有数据均存储在您的设备上。
    - **导出/导入**：支持 JSON 格式备份还原，或导出为 CSV 以供外部分析。
    - **回收站**：为所有交易提供软删除保护，防止误删。
- **现代 UI**：完全使用 Jetpack Compose 构建，遵循 Material 3 设计原则。

## 技术栈

- **Kotlin**: 开发语言
- **Jetpack Compose**: UI 框架
- **Room**: 本地数据库
- **Hilt**: 依赖注入
- **Kotlin Flow**: 响应式数据流
- **ViewModel**: 状态管理

## 运行环境

在 Android Studio 中打开项目。请确保您使用的是最新的稳定版本。

### 构建要求
- Android SDK 35
- Java 17
- Gradle 8.x
