# Ledger（记账）

[English](./README.md)

一款注重隐私、本地优先的个人安卓记账应用。

将每一个余额持有方（现金、银行卡、微信钱包、支付宝、公交卡、超市储值卡等）统一建模为**账户**。账户间**转账**是一等能力，既能还原真实支付路径，又不会把转账算进收支统计。

应用显示名：**Ledger**（包名 `com.dodo.accounting`）。

## 界面结构

| 底部 Tab | 作用 |
|----------|------|
| **首页** | 周期汇总（周 / 月 / 年 / 自定义）+ 按日分组的流水 |
| **统计** | 分析：分类排行、趋势、日历、筛选流水 |
| **资产** | 净资产概览、账户余额、快捷转账 |
| **设置** | 账户 / 分类与标签 / 预算与周期规则 / 备份 / 偏好 / 回收站 |

中间 **+** 打开快速记账；**长按 +** 启动语音记账（可在设置中关闭）。

## 核心功能

### 账户与流水

- **资产账户**：名称、图标、颜色、初始余额、归档、排序
- **支出 / 收入**：需选分类；可选备注与标签
- **转账**：转出 → 转入；不计入收支统计
- **快速记账**：金额键盘，支持简单表达式（如 `12+3.5`）、日期时间、标签、「再记一笔」
- **语音记账**：系统语音识别 → 解析金额、类型、账户、分类等（依赖设备语音引擎）
- **软删除**：流水进回收站，可恢复或彻底删除

> **说明：** 新建流水时**已不再提供「余额校正」**。历史中的校正记录仍可查看，并可移入回收站；界面以只读提示说明。

### 预算与计划

- **月度总预算**、**分类预算**
- 记支出时对所选分类给出预算提示
- **周期规则**（按月间隔）：在应用执行生成逻辑时，自动补记到期账单/收入

### 分类与标签

- 支出 / 收入分类分离，支持图标与颜色
- 设置中管理排序与增删
- 标签用于跨分类标记；可选「常用分类 / 标签优先」（按近期使用排序）

### 统计

- 范围：周 / 月 / 年 / 自定义
- 视图：**分类排行**、**趋势**、**日历**、**流水**
- 筛选：类型、账户、分类、标签、日期等
- 转账与历史余额校正不进入收支合计

### 数据与隐私

- **本地优先**：无云账号，数据在设备 Room 库中
- **JSON** 完整备份导入导出（含导入预览）
- **CSV** 流水导出
- **WebDAV** 可选：上传 / 拉取 JSON 备份（连接信息保存在本机偏好中）
- **金额隐藏**：隐私遮罩
- **主题**：浅色 / 深色 / 跟随系统
- 记账偏好：默认类型与账户、是否用当前时间、保存后继续记、语音开关等

## 技术栈

| 层级 | 选型 |
|------|------|
| 语言 | Kotlin |
| UI | Jetpack Compose、Material 3 |
| 数据库 | Room |
| 依赖注入 | Hilt |
| 异步 | Kotlin Flow + ViewModel |
| 序列化 | kotlinx.serialization（备份） |

## 主要代码结构

```
app/src/main/java/com/dodo/accounting/
├── data/           # Room 实体、DAO、仓库、预置数据
├── domain/         # 草稿、规则、金额、用例
├── di/             # Hilt 模块
└── ui/
    ├── screen/     # 各 Tab、记账 Sheet、统计、设置、语音解析
    ├── theme/      # 颜色、字体
    └── viewmodel/  # AccountingViewModel 与操作分发
```

## 运行环境

- Android Studio（建议最新稳定版）
- Android SDK **35**
- **Java 17**
- Gradle **8.x**
